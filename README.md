# ParsaTLS Corporate Website

Static website for **ParsaTLS Constructing Inc.** and its VaraTex product page.

## Local preview
Open `index.html` in a browser, or run a local static server.

## GitHub Pages
Publish from the `main` branch and repository root. After deployment, connect the custom domain `parsatls.com` and add a `CNAME` file only when the DNS configuration is ready.
